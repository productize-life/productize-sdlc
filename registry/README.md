# registry/

The **registry template** — copy `SDLC-SKILL-REGISTRY.template.md` into your own repo as
`SDLC-SKILL-REGISTRY.md` (the `/sdlc-registry` skill does this for you) and fill in every
`{placeholder}`.

The registry is the control plane of your SDLC skill set: it outranks any skill's self-claim,
maps phases to primary skills, maps agents to permitted skills, and carries your supersede and
drift-check logs. It is plain markdown on purpose — any AI agent can read it, not just Claude Code.

See [../docs/GETTING-STARTED.md](../docs/GETTING-STARTED.md) and
[../docs/USE-WITH-YOUR-AGENT.md](../docs/USE-WITH-YOUR-AGENT.md).
